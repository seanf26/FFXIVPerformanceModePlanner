# FFXIV Performance Mode Planner

A tool I built to help plan and preview midi arrangements for Bard Performance Mode in FFXIV. It has the ability to auto-transpose notes that are out of bounds (C3-C6 octave range) and save instrument choices into the exported track. It's a tool for personal use so I don't expect much to be added unless there are major changes to the in-game Performance Mode.

## Roadmap

- General improvements to both front and backend.
- Optimising the emulator environment to more accurately reflect note limitations - particularly with fast-paced drum tracks.
- Potentially supporting tracks with embedded electric guitar preset changes.
